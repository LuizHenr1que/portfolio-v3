## 📋 Sobre Este Portfólio

Este é meu **portfólio pessoal v3**, onde compartilho minha jornada como desenvolvedor Full Stack. O projeto foi desenvolvido com foco em **performance**, **acessibilidade** e **experiência do usuário**, apresentando uma interface moderna com animações suaves e design responsivo.

### 🎯 Objetivo
Demonstrar minhas habilidades técnicas através de:
- **Interface moderna** e profissional
- **Código limpo** e bem estruturado
- **Tecnologias atuais** do mercado
- **Experiência do usuário** otimizada

## 🔧 Para Desenvolvedores

Interessado em como foi desenvolvido? Você pode:

### Executar Localmente
```bash
# Clone o repositório
git clone https://github.com/LuizHenr1que/portfolio-v3.git

# Instale as dependências
npm install

# Execute o servidor de desenvolvimento
npm run dev
```

### Scripts Disponíveis
```bash
npm run dev      # Servidor de desenvolvimento
npm run build    # Build para produção
npm run preview  # Preview do build
npm run lint     # Verificação de código
```
